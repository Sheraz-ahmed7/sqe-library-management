# SQE Library Management

## Project Description

SQE Library Management is a software project developed as part of the Software Quality Engineering (SQE) course. The system is designed to manage library activities such as books, members, book searching, and library records.

The project follows a GitHub-based software development workflow with a focus on software quality, version control, issue tracking, testing, documentation, and project management.

## Main Features

* Book Management
* Member Management
* Book Search
* Testing and Quality Assurance
* Project Documentation

## Software Quality Engineering

This project demonstrates the use of Git and GitHub for managing software development activities, including issues, labels, project boards, documentation, testing, and version control.
